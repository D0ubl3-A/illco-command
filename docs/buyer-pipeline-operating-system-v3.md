## Platform Buyer Teaser

illcoai.tech is an AI workflow operating layer that can be embedded into an enterprise platform to reduce manual workflow handling, improve repeatability, and route uncertain outputs through auditable fallback paths. The 90-day integration path is scoped to one workflow, one connector, one quality dashboard, and one measurable ROI target.

## Vertical Buyer Teaser

illcoai.tech helps vertical workflow teams turn repeated operational tasks into controlled AI-assisted execution. The buyer value is faster throughput, lower manual handling cost, better auditability, and clearer retention loops inside an existing customer base.

## Follow-Up

Subject: Re: Strategic workflow AI review for [Company]

Quick follow-up. The useful part for [Company] is not a broad AI demo. It is a controlled workflow pilot with a defined 30/60/90 day path, a quality dashboard, and a fallback policy for uncertain outputs.

If useful, I can send the one-page target fit and benchmark summary before a call.

## Call Script

1. State the exact buyer workflow.
2. Show the 90-day integration path.
3. Show one quality metric and one cost or time metric.
4. Name the top risk before they do.
5. Ask whether the target workflow is worth diligence.

## Pipeline Stages

| Stage | Definition | Exit criteria |
|---|---|---|
| targeted | Target has product-fit signal only. | Named product owner, corp-dev path, and integration hypothesis found. |
| intro_sent | Buyer has received short thesis. | Reply, decline, or follow-up scheduled. |
| reviewing | Buyer is reading a teaser, memo, or diligence artifact. | Buyer asks a follow-up or goes quiet past follow-up window. |
| call_scheduled | First call is booked. | Call held or rescheduled once. |
| diligence_requested | Buyer asks for product, technical, customer, or metrics follow-up. | NDA, corp-dev, partnership, investment, or pilot path discussed. |
| stalled | No meaningful response after follow-ups. | Park, warm intro, or close no. |
| closed_no | Buyer not moving forward. | Reason captured. |
| active | Buyer is evaluating strategic transaction path. | Named sponsor, timeline, and next diligence step exist. |

## Outreach Rules

| Rule | Reason |
|---|---|
| Never lead with "we want to be acquired." | It weakens leverage and frames the company as distressed. |
| Lead with strategic workflow value. | Product leaders engage when the integration thesis is specific. |
| Every message gets one buyer-specific reason. | Generic outreach dies immediately. |
| Every serious conversation gets one proof artifact. | Buyers need evidence, not adjectives. |
| Keep corp-dev out of call one unless invited. | Product pull should create strategic tension first. |

## Kill Criteria

Stop outreach to a target if:

| Kill condition | Action |
|---|---|
| No named owner after 3 attempts | Park target for 30 days. |
| No buyer-specific workflow thesis | Keep in research. |
| No proof artifact for target | Do not send. |
| Buyer says not strategic | Capture reason and close lost. |
| Diligence stopper appears | Pause all serious conversations until remediated. |
